# Threads 自動投稿ボット

`posts.json` に書いた投稿を、予定時刻になったら Threads に自動で公開します。アフィリエイトリンクがある投稿は、公開した直後に自分の投稿へのリプライ（コメント欄）としてリンクを書き込みます。

GitHub Actions で毎時動くので、サーバーは要りません。Python の標準ライブラリだけで動きます。

## しくみ

1. GitHub Actions が毎時5分に `bot.py post` を実行します。
2. 予定時刻を過ぎた未公開の投稿があれば、時刻が早いものから **1回に1件だけ** 公開します。
3. `affiliate` がある投稿には、約30秒後に「【PR】」付きのリプライでリンクを書き込みます。
4. 公開した記録を `state.json` に保存してコミットします。同じ投稿が2回公開されることはありません。
5. リプライだけ失敗した場合は、次の実行でリプライだけをやり直します。

## 投稿の書き方（posts.json）

```json
{
  "id": "lime-tissue-culprit",
  "scheduled_at": "2026-11-05T20:00:00+09:00",
  "text": "帰宅したらティッシュが部屋中に散らばってました。\n\nゆず「わたしじゃないです」\nライム「……」",
  "image_url": "https://example.com/photo.jpg",
  "affiliate": {
    "text": "【PR】ライムのいたずら対策に使っているティッシュケース",
    "url": "https://自分のアフィリエイトリンク"
  }
}
```

| 項目 | 説明 |
|---|---|
| `id` | 投稿ごとに違う名前。公開後に変えると、別の投稿として再公開されます |
| `scheduled_at` | 公開する日時。最後に `+09:00`（日本時間）を必ず付けます |
| `text` | 本文。500文字まで。改行は `\n` |
| `image_url` | 写真を付けるときの URL。インターネットに公開されている `https://` の画像である必要があります。なければ `null` |
| `affiliate` | 省略可。`text` に「PR」「広告」などの表記がなければ、先頭に自動で「【PR】」を付けます |

保存したら、手元で確認できます。

```bash
python threads_bot/bot.py check            # 書き方の検証
python threads_bot/bot.py post --dry-run   # 次に公開される内容を表示（投稿はしない）
```

## はじめの設定

### 1. Threads API のアクセストークンを取る

1. [Meta for Developers](https://developers.facebook.com/) でアプリを作り、ユースケースに「Threads API にアクセス」を追加します。
2. 権限 `threads_basic` と `threads_content_publish` を有効にします。
3. 自分の Threads アカウントをテスターに追加して承認します。
4. 長期アクセストークン（有効期限60日）を発行します。

### 2. GitHub のシークレットに登録する

リポジトリの Settings → Secrets and variables → Actions で登録します。

| 名前 | 中身 | 必須 |
|---|---|---|
| `THREADS_ACCESS_TOKEN` | 長期アクセストークン | 必須 |
| `THREADS_USER_ID` | Threads のユーザーID。未設定なら `me` を使います | 任意 |
| `GH_PAT` | トークン自動更新で、シークレットを書き換えるための個人アクセストークン（Secrets の読み書き権限） | 任意 |

`THREADS_ACCESS_TOKEN` を登録するまでは、ワークフローは何もせずに終わります。

### 3. 試しに動かす

Actions タブ →「Threads 自動投稿」→ Run workflow で、`dry_run` にチェックを入れたまま実行すると、投稿せずに内容だけ確認できます。

## トークンの更新

長期トークンは60日で切れます。「Threads トークン更新」ワークフローが毎月1日と15日に更新します。`GH_PAT` を登録しておくと、新しいトークンでシークレットも自動で書き換えます。

## 守っておきたいこと

- **PR表記は外さない。** 2023年10月からのステマ規制（景品表示法）で、アフィリエイトリンクには広告であることの表記が必要とされています。このボットは表記のないリプライを公開しません。
- **投稿しすぎない。** Threads API の上限は24時間で投稿250件・リプライ1,000件ですが、上限まで使うとスパム扱いされるおそれがあります。1日1〜2件が目安です。
- **リンクは1投稿5個まで。** 6個以上だと Threads API が投稿を拒否します。
- **アフィリエイト各社の規約を確認する。** SNS への掲載や短縮URLの可否など、ルールはサービスごとに違います。
